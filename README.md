Учебный проект, в рамках которого был проведен разведочный анализ данных (EDA) о рынке недвижимости выбранного региона. Целью проекта было выявление ключевых факторов, влияющих на стоимость объектов, исследование распределения характеристик объектов, а также территориального распределения цены. 

### **Цель проекта**

1.  Понять распределение объектов по стоимости, году постройки, этажности, состоянию домов, по наличию вида на набережную, жилой квадратуры.
2.  Оценить, как состояние домов, класс жилья, наличие вида влияют на стоимость.
3.  Визуализировать «тепловую карту» цен и обнаружить самые дорогие/дешевые локации.
4.  Определить, какие характеристики недвижимости сильнее всего коррелируют с его стоимостью.

### **Результаты и выводы**

*   Наибольшую положительную корреляцию с общей стоимостью показывает **жилая площадь** дома, а также **класс жилья**.
*   С помощью визуализации геоданных выделяются дома более дорогие, находящиеся ближе к водоемам
*   Такие факторы, как год постройки, состояние домов, количество этажей не оказывают существенного влияния на стоимость
